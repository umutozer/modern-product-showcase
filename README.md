# modern-product-showcase

Cep telefonu ve bilgisayar satışları için modern, minimalist, tek sayfalık tanıtım websitesi.

## Teknoloji

| | |
|---|---|
| Mimari | html-css-js |
| Frontend | HTML + Tailwind CSS + Vanilla JS |
| Backend | None |
| Veritabani | None |
| Deployment | Static Hosting (Netlify, Vercel vb.) |

## Kurulum

```bash
index.html dosyasini tarayicinizda acin

# veya Live Server kullanin:
npx live-server .
```
